# Developer Portfolio

A polished, responsive developer portfolio landing page built with plain HTML, CSS, and JavaScript.

## Preview

Open `index.html` directly in any modern web browser.

## Features

- Responsive 2x2 project grid
- Fictional developer profile and projects
- Light and dark themes
- Theme preference saved in local storage
- System color scheme detection
- No build tools or dependencies

## Run locally

Open `index.html` in a browser, or serve the folder with a simple static server:

```sh
python -m http.server 8000
```

Then visit `http://localhost:8000`.
